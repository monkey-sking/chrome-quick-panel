# Chrome 应用商店文案（简体中文）

## 名称

书签 / 历史 快捷面板

## 简短说明（≤132 字符）

工具栏一键打开书签与历史：点一下切书签、再点一下切历史，悬停设备即可看该设备的标签页。纯本地，不上传任何数据。

## 详细说明

把 Chrome 里藏得很深的「书签」和「历史记录」放到工具栏，一下就能打开。

**点击工具栏图标**
- 一次点开书签面板，再一次点开历史面板，循环交替
- 面板顶部也可以直接切换「历史 / 书签」

**书签面板**
- 顶部实时搜索书签
- 「最近添加」默认展开，书签栏 / 其他书签可折叠，支持嵌套文件夹
- 右上角图标直达书签管理器
- 点书签在新标签页打开

**历史面板**
- 打开历史记录页面（⌘Y / Ctrl+Y）
- 您的设备：显示已登录同步的 Mac / iPhone / iPad 等设备
- 鼠标移到某台设备上，旁边像原生二级菜单一样滑出这台设备打开的标签页

**快捷键**
- `⇧⌘Y` 直接打开历史面板，`⇧⌘U` 直接打开书签面板

**其他**
- 自动跟随系统浅色 / 深色主题
- 按 Esc 关闭面板
- 不申请任何网站访问权限，不注入页面，不读取网页内容，不发送任何数据

> 说明：Chrome 未开放调用系统自带历史下拉面板的接口，本扩展使用 Chrome 官方 API 复刻了相同的信息结构，数据完全来自本地。

## 单一用途说明（Single purpose）

在工具栏提供书签与最近历史的一键查看入口，不包含其他无关功能。

## 权限用途说明（Permission justification）

| 权限 | 用途说明 |
| --- | --- |
| `tabs` | 读取窗口 / 标签页地址，用于判断面板窗口是否已打开并聚焦，避免重复开窗；不读取网页内容。 |
| `sessions` | 读取已同步设备列表，用于渲染「您的设备」；未登录同步时为空。 |
| `bookmarks` | 读取与搜索本地书签，用于书签面板。 |
| `contextMenus` | 在工具栏图标的右键菜单中提供历史 / 书签入口。 |
| `favicon` | 使用 Chrome 本地缓存的网站图标，不发起网络请求。 |
